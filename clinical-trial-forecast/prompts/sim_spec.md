ONE PHENOMENON, ONE ADJUSTMENT — no double counting and no stacked conservatism. Calibration cuts both ways: a discount the evidence does not support is as much a calibration error as an optimistic centre.
- In every adjustment's basis, say what it prices and what it does not. Before adding or sizing an adjustment, check whether another parameter's anchors already embed it. WHAT THE SHEET MUST CONTAIN
1. `trial`: the design to simulate, chosen from the best evidence (registered design > sponsor statements > pivotal precedent in the indication > regulatory guidance) — arms with N, population, duration, every primary / co-primary / key secondary endpoint with its type, timepoint, pre-specified analysis and success rule, alpha, multiplicity rule, the trial-level success definition, and the program rule (how many trials, whether all must win, and which uncertainties are shared across them). Say in `design_basis` where each design element comes from.
2. `parameters`: every quantity the model needs, each with an id, `kind`, a distribution, a point estimate, a 90% interval, units, `basis` (HOW the value was chosen, in plain language a non-statistician can follow), `sources` (citations copied exactly from the files), `alternatives_considered`, `confidence`, and `expected_sensitivity`.
   - EPISTEMIC parameters (what we do not know about the truth): e.g. the true control-arm response under the phase 3 design and population; the true treatment effect the drug will show in phase 3, built from the phase 2 estimate and a phase 2 → phase 3 translation calibrated on precedent pairs in this indication; design-shift effects (background therapy, region mix, baseline severity, dosing regimen differences between phase 2 and phase 3); correlation between co-primary endpoints; dropout and how missing data are handled. Give each a genuine probability distribution — never "fixed" — and state what evidence sets its centre and its width (sample sizes, between-trial heterogeneity, number of precedent pairs).
   - THE EFFECT CHAIN — price every gap between the phase 2 result and the phase 3 truth ONCE (see "Effect-chain accounting" under RULES). An observed phase 3 / phase 2 ratio from precedent pairs already contains those pairs' own winner's curse, regression to the mean and typical design changes; a further term is allowed only for how THIS program differs from those pairs, with the evidence for the difference.
   - Winner's curse / selection: derive it from the selection rule actually used (best of k doses picked on the observed effect; a dose picked for PK, safety or convenience; several arms pooled) and count only selection beyond what the calibration pairs already carry. A dose chosen for reasons other than its observed efficacy carries little or no selection correction.
   - Precedent pairs: use every like-for-like pair that meets one stated inclusion rule, including pairs where phase 3 matched or beat phase 2. If some pairs match the target program on a feature that plausibly changes how much of the phase 2 effect carries into phase 3 (e.g. the kind of design change between phases, the endpoint, the modality), you may weight them more heavily in the translation instead of adding a separate discount for that feature; record the weights and the reason in the parameter's `basis`. State the direction of any selection or file-drawer bias in the pair set with its arithmetic before deciding whether to adjust for it.
   - Mechanism outside the prior's class: when the asset's mechanism differs from the class a shrinkage prior is built on (e.g. an extra target, a new modality), price that ONCE as a membership mixture — a weight on "behaves like the class" vs a wider "out-of-class" prior — with the weight set by a stated estimator. Do not also add a judged additive increment for the same upside or downside.
   - Active comparator (head-to-head designs only): build the comparator's true response from the best evidence available and say how you weighted it. Prefer large randomized arms under a design and population like the phase 3, placebo- or backbone-controlled pivotal arms first; smaller, phase-2-scale, single-region, open-label or active-controlled arms can also move the centre when they are closer to the phase 3 population or design, or when they are all there is. Weight each source by its size and its relevance to the phase 3, record the weights in `basis`, and widen the distribution when the centre rests on weaker evidence. Two accounting rules still hold: any factor that transports a margin from phase 2 to phase 3 must exclude comparator effects already priced in the comparator benchmark, and if the asset's phase 2 datum also informs the comparator benchmark (shared class prior), update both jointly.
   - ALEATORIC model parameters (randomness of one trial given the truth): the sampling model per endpoint (binomial responders per arm, normal for continuous, etc.), dropout process and imputation rule (e.g. non-responder imputation), randomization ratio, interim analyses if any.
   - DESIGN parameters (fixed by the protocol): N per arm, alpha, timepoints.
   - OPERATIONAL parameters feeding the failure modes.
3. `dependencies`: correlations the builder must honour (e.g. control rate and treatment effect; co-primary endpoints; the two trials of a program sharing the same true effect), each with a rho or a description and its basis.
4. `failure_modes`: non-efficacy ways the program can technically fail (safety/tolerability signal leading to a hold or a failed benefit-risk, immunogenicity, manufacturing/CMC, enrollment failure or termination, regulatory-design rejection), each with a probability distribution and basis. Be concrete about how each enters the success definition (multiplicative independent, or conditional).
5. `scenarios`: 4-10 named alternative worlds, chosen to show where the forecast is most fragile (e.g. "phase 2 effect fully replicates", "effect attenuates like the median precedent pair", "placebo response at the high end of pivotal precedent", "the second co-primary endpoint is the binding constraint", "larger N", "monotherapy vs background-therapy design"), as parameter overrides, each with why it matters. Worth considering where relevant: how much weight the asset's own phase 2 gets (weaker or flat priors, phase 2 at face value); class membership fixed at 0 or 1 where the sheet uses a membership mixture; true effect = phase 2 estimate × a single precedent ratio with no other discount; and the sponsor's powering assumption, if public. Where a scenario changes the structure rather than a parameter value (a flat prior, a single-ratio translation), express it as an override of a switch parameter that you define in `parameters` (kind `design`) and describe in `notes_for_builder`.
6. `reference_class`: the external base rate of technical success for comparable programs (e.g. phase 3 success after a positive phase 2 for biologics in this indication / class), with sources — the builder will show the model's PTS next to it. Blend the outside view into the effect where your best read of the data supports it, and state the weight and why. If the phase 2 estimate is already shrunk toward a class prior built on the same trial record, that record is already in the effect: either give the blend only what the shrinkage does not cover, or weaken the shrinkage prior — never apply both at full strength.
7. `key_uncertainties`, `assumptions`, `notes_for_builder` (anything the builder needs that the structure above cannot express), and `change_log` (round 1: "initial"; later rounds: what changed and why, referencing the critic's request numbers).

RULES
- Every number must be traceable: copy n/N, rates, SDs, CIs exactly from the files and cite them in `sources`; if you derive a value (e.g. a logit-scale SD from a CI, a pooled rate), say how in `basis` and mark it "(derived)". Do not invent precedent trials or numbers.
- Prefer simple, explainable distributions (beta for rates with an effective sample size you justify; normal/logit-normal for effects; triangular or uniform when only a plausible range is known). State the effective sample size or the between-study heterogeneity you used for the width.
- Shrinkage and translation must be explicit parameters (so the report can show their effect), not baked into the effect estimate — but explicit is not additive: see the next rule.
- Effect-chain accounting: every discount or adjustment names the specific gap it explains and the evidence that isolates it, and each mechanism has exactly one home in the sheet. Before returning, write a double-counting audit as the FIRST entries of `assumptions`, each prefixed "DOUBLE-COUNT AUDIT:": every pair of parameters that could price the same mechanism (e.g. class shrinkage vs outside-view blend; precedent-pair translation vs a separate winner's-curse or design-shift haircut; comparator lift inside a margin factor vs the comparator benchmark; a trough/regimen penalty in two places; an endpoint-translation allowance in two places) and why they do not overlap or which one you removed.
- Caution goes into width, not into the centre. Every centre is an estimator applied to cited data (say which). A judged adjustment with no estimator is centred at no shift — 0 for an additive term, 1 for a multiplicative factor — with a width that reflects the disagreement; do not nudge centres in the adverse direction "to be conservative" — several small adverse nudges stack into a biased forecast.
- Check the composite: the sheet's implied share of the phase 2 effect that survives into phase 3 (all translation factors multiplied) should sit inside the spread of the precedent pairs' observed ratios. If it is lower or narrower, say in `basis` which program-specific evidence justifies it, or revise. List the precedent pairs' observed ratios (pair, phase 2 effect, phase 3 effect, ratio, source) in `notes_for_builder` so the builder can show the comparison; for time-to-event endpoints use the log hazard ratio scale.
- If the evidence for a quantity is thin, say so in `basis`, widen the distribution, set `confidence: low`, and add the missing item to `key_uncertainties` — do not paper over gaps.
- Use only public information; never include anything from the intake notes that is not traceable to a public source.
