# Security Policy

## Reporting Security Issues

The security of our systems and user data is Anthropic's top priority. We appreciate the work of security researchers acting in good faith in identifying and reporting potential vulnerabilities.

Please don't report security issues in public GitHub issues or pull requests. Our security program is managed on HackerOne, and we ask that any validated vulnerability in this repository, including files bundled in it, be reported through their [submission form](https://hackerone.com/4f1f16ba-10d3-4d09-9ecc-c721aad90f24/embedded_submissions/new).

## Third-party services

For a vulnerability in a service run by a third party, please contact that provider directly.

## Anthropic Bug Bounty

Our Bug Bounty Program Guidelines are defined on our [HackerOne program page](https://hackerone.com/anthropic).
